# Nova - Rule-Based AI Chatbot

## DecodeLabs AI Internship - Project 1

### Project Overview

Nova is a Python-based Rule-Based AI Chatbot developed as part of the DecodeLabs Artificial Intelligence Internship.

The chatbot uses predefined rules and if-elif-else decision-making to respond to user inputs and runs continuously until the user chooses to exit.

## Project Objectives

- Build a simple rule-based chatbot
- Practice Python control flow and decision-making
- Handle greetings and exit commands
- Create a continuous conversation loop
- Provide predefined responses to different user inputs

## How It Works

Nova processes the user's input and checks it against predefined rules using if-elif-else conditions.

If a matching rule is found, the chatbot provides the corresponding response.

The chatbot continues running inside a while loop until the user enters an exit command.
